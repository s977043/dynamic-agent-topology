# Support

Dynamic Agent Topology (DAT) is an experimental specification and evaluation repository. Route requests by type so questions remain reproducible and security-sensitive information stays private.

## Usage and adoption questions

Use the repository **Usage or adoption question** Issue form for public, reproducible questions about:

- adopting DAT in an existing repository;
- schemas and validators;
- topology, role, policy, or adapter semantics;
- experiment tooling and examples.

Include the DAT version or commit, adoption stage, runtime or validator context, and the smallest public example that reproduces the question.

## Bug reports

Use the **Bug report** Issue form for reproducible defects. Include expected behavior, actual behavior, reproduction steps, and sanitized evidence.

## Research and design proposals

Use the **Proposal** Issue form. Start from the observed problem or evidence, describe the smallest useful change, and explain how it could be evaluated.

During an active experiment freeze, proposals can be recorded while implementation remains deferred.

## Security issues

Do not publish exploit details, credentials, private source code, confidential prompts, or unsanitized traces in a public Issue.

Follow [SECURITY.md](SECURITY.md) for security reporting guidance.
