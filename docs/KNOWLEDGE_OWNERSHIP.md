# プロジェクト知識と環境メモリの分担

Issue #159施策⑤の運用ガイドです。共有するプロジェクト知識はリポジトリに記録し、端末固有の観測は環境メモリに置きます。実行権限・独立レビューは[AGENTS.md](../AGENTS.md)と[AGENT_HARNESS.md](AGENT_HARNESS.md)、Freeze範囲は[pilot/freeze.yaml](../experiments/EXP-001-t0-vs-t1/pilot/freeze.yaml)と[既存Freeze手順](../experiments/EXP-001-t0-vs-t1/pilot/FREEZE.md)、EXP-001の進行状態は[Issue #15](https://github.com/s977043/dynamic-agent-topology/issues/15)を正本とします。この分担は新しい承認Gateを定義しません。

## 保存先

| 情報 | 正本・保存先 | 更新方法 |
|---|---|---|
| 共有する判断・失敗・対策・検証手順 | docs/、knowledge/、scripts/と関連Issue/PR | 原文Evidenceを付けてPRへ。独立レビューと既存merge条件を適用 |
| 学習した失敗と再発観測 | knowledge/learning-ledger.json | 日付不明は補完しない。生成Markdownと同期しvalidatorで検証 |
| 実行中の状態・進行許可 | 対象Issue/PR（EXP-001はIssue #15） | 実際のCI・Reviewer判断・原本証跡へリンク |
| OS/CLI版・ローカルパス・接続可否 | 環境メモリ、必要な非秘密情報はENVIRONMENT_USAGE.md | 採取日時・環境ID・実行階層を付け、使用前に再確認 |
| 一時作業・未検証の仮説 | 作業セッションの記録、または明示したproposal | 検証済みの共有ルールと混同しない |
| 認証情報・秘密値・未加工trace | 承認済みの非公開保管先 | memoryや公開Gitへコピーしない。公開資料は必要範囲の派生Evidence |

環境メモリには共有手順のコピーを重ねず、repoのpath・commit SHA・Issue/PRリンクを残します。同じパスが別端末にあるとは推測せず、Mac・ThinkPad・各クラウドの観測を区別します。

## 使用・引き継ぎ

1. プロジェクト作業を始めるときは最新repoのAGENTS.mdと関連Issueを読み、メモリの手順や進行状態を照合します。古いチェックポイントを現在の実行許可として使いません。
2. 環境メモリのパス・版・接続情報は、その環境で非秘密の読み取り確認を行います。確認できない値はunknownとして保持し、別環境の値で埋めません。
3. 共有すべき知見が見つかったらEvidence・対象範囲・限界・最小変更をrepoの提案へ移します。メモリを書き換えただけでは、共有ルールやGuardを変更したことになりません。
4. 別セッションにはrepo SHA、原文資料のリンクまたはファイル、未確認事項を渡します。秘密値を渡さず、作者の結論要約だけを独立レビュー材料の代替にしません。
5. 提案がmergeされたら、環境メモリにある重複説明は正本への参照に置き換えます。共有ルールとメモリが矛盾する場合は正本を確認し、未確認の実行を停止して矛盾を記録します。

新しい環境からは他の端末のmemoryを取得・変更できるとは限りません。今回、Mac・ThinkPad・他クラウドのmemoryへのアクセス・変更は実測していません。実際にアクセスした記録がない端末のmemory移行を完了扱いせず、各環境の担当者が重複・古い進行状態を確認します。この文書のmergeは既存memoryの移行完了を意味しません。

## 記録例

```text
環境ID: <非秘密の識別子>
採取日時と実行階層: <日時、host/container/sandbox>
repo SHA・正本リンク: <確認したcommitとpathまたはIssue>
観測: <非秘密の値、実行した確認、unknown>
適用範囲と未確認: <この環境で使える作業、別端末は未確認>
```

正式な環境JudgmentやRun ACCEPTはこのメモ欄で代替しません。共有環境のCLI認証アカウントを切り替えず、既存のコマンド単位の認証手順を守ります。機密情報を消す目的の履歴書き換えや削除は、このガイドから自動実行しません。
