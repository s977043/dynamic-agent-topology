# Support

Dynamic Agent Topology is an experimental specification and evaluation repository. Use the narrowest public route that matches your request.

## Usage and adoption questions

Use the **Usage or adoption question** Issue Form for questions about:

- adopting DAT in an existing repository;
- schema or validator behavior;
- topology, role, policy, or adapter semantics;
- examples, experiment tooling, or repository integration.

Include the smallest reproducible context that can be shared publicly.

## Bugs

Use the existing **Bug report** Issue Form and include a minimal reproduction and sanitized evidence.

## General proposals

Use the existing **Proposal** Issue Form for repository, schema, runtime, topology, policy, or experiment-method changes that start from a concrete problem or observed friction.

## Research-derived proposals

Use the **Research or design proposal** Issue Form when a paper, benchmark, external framework, or other research source materially motivates the proposal.

Keep these separate:

- what the source actually claims;
- DAT's interpretation;
- the hypothesis to test;
- the cheapest useful evaluation;
- the evidence that would reject or defer the proposal.

A source citation is not evidence that a DAT design is effective.

## Security

Do not post exploit details, credentials, private source code, confidential prompts, or sensitive traces in public Issues.

Follow [SECURITY.md](SECURITY.md).
