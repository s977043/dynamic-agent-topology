# Metrics

## Outcome
- task success
- regression rate
- acceptance-criteria satisfaction

## Collaboration
- topology adherence
- role/boundary violations
- handoff failures
- dependency pass rate
- dependency resolution steps

## Evaluation quality
- reviewer precision
- verifier false-accept rate
- evidence completeness
- human correction count

## Efficiency
- input/output tokens
- wall-clock latency
- agent invocations
- coordination transitions
- cost per successful task

No single metric is a universal optimization target.
